# Лабораторная работа №1 по АКОС

Скрипты для мониторинга заполненности папки, архивации и удаления старых файлов при превышении заданного порога.

Проект реализован на **10 баллов**:
- Shell-скрипты для Linux: `src/cleanup.sh` и `tests/test_runner.sh`.
- Batch-скрипты для Windows: `src/cleanup.bat` и `tests/test_runner.bat`.
- Поддержка сжатия LZMA при `LAB1_MAX_COMPRESSION=1`.
- Тесты работают в обычном user-space без прав суперпользователя (root) и оперируют данными от 0.5 GB.

---

## Как решены задачи и что использовалось

### 1. Проверка заполнения папки в процентах
- **Как решили**: Скрипт поддерживает два режима работы. Если передан четвертый аргумент (или задана переменная `LOG_MAX_SIZE_MB`), процент считается от этой квоты (удобно для тестов в обычном каталоге без монтирования). Если квота не указана, скрипт автоматически берет общий размер раздела, на котором находится каталог.
- **Главные инструменты**: `du -sk` (занятый объем каталога в КБ), `df -k` (размер диска/раздела), целочисленное деление `$((CURRENT_KB * 100 / TOTAL_KB))`.

### 2. Проверка порога и расчет объема для очистки
- **Как решили**: Сравниваем процент с порогом `X%`. Если порог не превышен, скрипт завершает работу без действий. Если превышен, высчитывается целевой допустимый объем и дельта - количество килобайт, которое обязательно нужно освободить.
- **Главные инструменты**: Условие `[ "$PERCENT" -le "$THRESHOLD" ]`, расчет дельты `$((CURRENT_KB - TARGET_KB))`.

### 3. Фильтрация и отбор N старейших файлов
- **Как решили**: Список файлов в папке сортируется по дате изменения (от самых старых к новым). Скрипт по очереди берет файлы и суммирует их объем. Как только набранный вес покрывает расчетную дельту, перебор останавливается. Это гарантирует, что удаляются только самые старые файлы и ровно в том количестве, которое нужно для возврата в рамки порога.
- **Главные инструменты**: `ls -tr` (в Windows: `dir /b /a-d /od`), построчное чтение `while read`, проверка обычного файла `[ -f ]`, замер размера файла `du -k`.

### 4. Архивация и удаление файлов
- **Как решили**: Отобранные файлы упаковываются в архив в папку бэкапов. После успешного создания архива те же файлы удаляются из папки логов. После очистки выводится итоговый процент занятости.
- **Главные инструменты**: `tar -czf` (сжатие gzip по умолчанию), ключ `-C` (для исключения полных путей внутри архива), `date +%Y%m%d_%H%M%S` (уникальный штамп времени), `rm -f`.

### 5. Режим максимального сжатия LZMA (на 9 баллов)
- **Как решили**: Перед вызовом tar проверяется значение переменной окружения `LAB1_MAX_COMPRESSION`. Если выставлена единица, расширение меняется на `.tar.lzma`, а tar запускается с флагом `--lzma`.
- **Главные инструменты**: Проверка `[ "${LAB1_MAX_COMPRESSION:-0}" = "1" ]`, флаг архивации `tar --lzma -cf`.

### 6. Автоматизированные тесты в user-space (на 9-10 баллов)
- **Как решили**: Скрипт подготавливает изолированную среду `test_env`, прогоняет 5 сценариев и автоматически удаляет за собой мусор через `trap`. Во всех сценариях размер папки превышает 0.5 GB (от 600 до 900 MB). Файлы создаются мгновенно за счет предварительного выделения блоков.
- **Главные инструменты**: `fallocate -l` / `truncate -s` (создание файлов без долгой записи нулей), `touch -d` (установка точного времени изменения файлов), `tar -tf` / `tar -tzf` (проверка целостности и содержимого архивов), `trap ... EXIT` (гарантированная очистка окружения).

### 7. Реализация для Windows (на 10 баллов)
- **Как решили**: Аналогичный функционал реализован в виде `.bat` файлов без использования сторонних утилит.
- **Главные инструменты**: `setlocal enabledelayedexpansion`, `dir /b /a-d /od` (сортировка по дате), `fsutil file createnew` (быстрое создание файлов >= 0.5 GB), встроенный в Windows `tar.exe`.

## Использование (Linux)

### Запуск очистки:
```bash
./src/cleanup.sh [путь_к_логам] [порог_%] [путь_к_бэкапам] [квота_МБ]
```

Примеры:
```bash
# Очистка папки ./log при превышении 70%, бэкапы в ./backup (размер диска из df)
./src/cleanup.sh ./log 70 ./backup

# С квотой 1000 MB (удобно для user-space)
./src/cleanup.sh ./log 70 ./backup 1000

# Сжатие LZMA (на 9 баллов)
LAB1_MAX_COMPRESSION=1 ./src/cleanup.sh ./log 70 ./backup 1000
```

### Запуск тестов:
```bash
chmod +x src/cleanup.sh tests/test_runner.sh
./tests/test_runner.sh
```
