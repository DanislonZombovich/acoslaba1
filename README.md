# Лабораторная работа №1 по АКОС

Скрипты для мониторинга заполненности папки, архивации и удаления старых файлов при превышении заданного порога.

Реализовано на 10 баллов:
- Shell-скрипты для Linux: `cleanup.sh` и `test_runner.sh`.
- Поддержка сжатия LZMA через переменную окружения `LAB1_MAX_COMPRESSION=1`.
- Batch-скрипты для Windows: `cleanup.bat` и `test_runner.bat`.
- Все тесты работают в обычном user-space без root-прав и создают тестовые данные от 0.5 GB.

## Структура проекта

- `cleanup.sh` - основной рабочий скрипт для Linux.
- `test_runner.sh` - автоматические тесты (5 тест-кейсов) для Linux.
- `cleanup.bat` - скрипт очистки для Windows.
- `test_runner.bat` - автоматические тесты для Windows.
- `uslovie` - текст задания лабораторной работы.

## Использование (Linux)

### Запуск очистки:
```bash
./cleanup.sh [путь_к_логам] [порог_в_%] [путь_к_бэкапам] [квота_в_МБ]
```

Примеры:
```bash
# Очистка папки ./log при превышении 70%, бэкапы в ./backup (размер папки берется из df)
./cleanup.sh ./log 70 ./backup

# То же самое, но с заданной квотой в 1000 MB (удобно для user-space)
./cleanup.sh ./log 70 ./backup 1000

# Запуск с максимальным сжатием LZMA (на 9 баллов)
LAB1_MAX_COMPRESSION=1 ./cleanup.sh ./log 70 ./backup 1000
```

### Запуск тестов:
```bash
chmod +x cleanup.sh test_runner.sh
./test_runner.sh
```

## Использование (Windows)

### Запуск очистки:
```cmd
cleanup.bat [путь_к_логам] [порог_в_%] [путь_к_бэкапам] [квота_в_МБ]
```

Пример:
```cmd
cleanup.bat log 70 backup 1000
```

### Запуск тестов:
```cmd
test_runner.bat
```
